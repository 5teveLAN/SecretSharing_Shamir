6-1 · 逐像素擷取

一個像素，就是三個 Secret

每個像素 pixel = (R, G, B)

程式逐像素讀取彩色影像，把 R、G、B 三個通道的數值分別抽出來； 每個值都落在 0–255，都可以當成一條多項式的常數項 a0。

  • R: 0–255
  • G: 0–255
  • B: 0–255

為什麼是 GF(28)？
通道值共 256 種，但 256 不是質數、沒有 GF(256)； 所以改用 GF(28)：加減用 XOR，乘除查表完成。

6-2 · 產生流程

從一張原圖，到 n 張分享影像

  • 1 · 逐像素取 R、G、B
  • 2 · 建立 r−1 次多項式
  • 3 · 代入 x = 1…n
  • 4 · 寫回 n 張 share

6-3 · 多項式與編碼矩陣

每個通道，各自一條多項式

c = R, G, B fc(x) = c + a1x + ⋯ + ar−1xr−1

01 · R 通道

a0 = R

代入 x = 1…n，得到 S1-R、S2-R、…、Sn-R。

02 · G 通道

a0 = G

換一組亂數係數、同一組 x 再算一次，就是 G 通道的 n 個分量。

03 · B 通道

a0 = B

三條多項式互不相干；所有運算都在 GF(28) 裡完成。

同一組 x，三條多項式
把 x = i 代入三個通道，就得到第 i 張 share 的 (Si-R, Si-G, Si-B)； 在硬體實作上，這一步就是 HW Encoding Matrix。

6-4 · 分享影像

每張 share，看起來都只是雜訊

每個像素位置算出的值 yi，寫回第 i 張 share 的同一個位置；三個通道都寫完， 就得到一張完整的分享影像。

  • S1 = { S1-R, S1-G, S1-B }
  • S2 = { S2-R, S2-G, S2-B }
  • … Sn

少於 r 張：什麼都看不出來
係數 a1 … ar−1 是亂數， 單張 share 的每個像素都均勻分布在 0 到 255 之間。

任 r 張：原圖就能回來
湊到 r 個點即可解出多項式，取回常數項 a0， 也就是該通道的原始值。

6-5 · 門檻還原

高斯消去法：解聯立多項式求回機密

在 (r, n) 機制中，收集任意 r 位參與者的分享值 {(x1, y1), …, (xr, yr)}。 依論文第二章，代入多項式建立 r 個聯立方程： yi = a0 + a1xi + ⋯ + ar−1xir−1

  • 1
    建立凡德蒙增廣矩陣 以點座標次方項與分享值組成 [V \mid y] 線性系統。
  • 2
    前向消去化為階梯形 在有限體以列運算（加減為 XOR、除法為乘法逆元）消為上三角矩陣。
  • 3
    反向代入求得常數項 a₀ 由下而上反向求解未知數，解得 a0 即為原影像像素通道值。

方法比較：拉格朗日插值可直算常數項 a0；高斯消去法為通用代數解法，可同時解出整條多項式所有係數。

6-6 · 本章小結

拆分與還原：完整的機密影像分享

從逐像素通道多項式拆分，到湊齊門檻利用高斯消去法或拉格朗日插值還原原圖。

01

逐像素、逐通道

R、G、B 各自是一條多項式的常數項；三個通道都處理完，才算完成一個像素。

02

全程在 GF(2⁸)

加減用 XOR、乘除查表，所有中間值都留在 0 到 255，不會溢位，也能精準還原。

03

任 r 張才是門檻

少於 r 張只是雜訊；湊滿 r 張才能解出多項式，與藏在 a0 的像素值。

核心還原法 —— 用拉格朗日插值、行列式（克拉瑪公式）或高斯消去法， 從 r 張 share 取回 a0，把整張原圖無損重建。
