4-1 · 有限體結構

兩種有限體的本質與運算規則

素數體 · GF(p)

整數模運算（Modular Arithmetic）

元素為整數集合 {0, 1, ..., p−1}。
所有加、減、乘運算直接計算後 mod p。
除法乘上乘法逆元：a / b = a · bp−2 (mod p)。

缺點：若用在影像（0~255），取 p=257 會超出 1 Byte，無法直接存成像素。

擴展體 · GF(28)

多項式模運算（Polynomials over GF(2)）

元素看成最高 7 次的多項式，長度恰好 8-bit（0~255）。
加減法：二進位無進位加法，直接等價於 XOR。
乘除法：多項式乘除後模不可約多項式 P(x)。

優點：運算結果嚴格封閉在 [0, 255]，零浪費、不溢位。

4-2 · 加法與減法

加法等於減法，全都是 XOR

在 GF(28) 裡，係數來自 GF(2) = {0, 1}。模 2 的世界中：
1 + 1 = 0，且 0 − 1 = 1。

核心性質 a + b = a − b = a ⊕ b

程式實作：
不用做任何 Overflow 防護或取模，單一指令搞定！ 

add(a, b) { return a ^ b; }
sub(a, b) { return a ^ b; }

位元運算範例

  01010011 (0x53 = 83)
⊕ 00110101 (0x35 = 53)
-----------------------
  01100110 (0x66 = 102)

  • 無進位（Carry-less）
  • 自反性：a ⊕ a = 0
  • CPU 單週期完成

4-3 · 乘法與除法原理

不可約多項式 P(x) 與乘法逆元

多項式直接相乘次數會超過 7 次（大於 255）。為了封閉在 8-bit 內，相乘後必須模一個不可約多項式（相當於素數體裡的質數）。

本原多項式 P(x) = x8 + x4 + x3 + x2 + 1

其二進位表示為 1 0001 11012，即十六進制的 0x11d（第 8 bit 溢出時拿來 XOR 消除）。

為什麼除法能進行？

因為 P(x) 是不可約多項式，GF(28) 形成一個體（Field）：

• 除了 0 以外，每個非零元素都存在唯一的乘法逆元 a−1。
• 除法定義為乘以其逆元：a / b = a · b−1。
• 這保證了後續解聯立方程、拉格朗日插值一定解得出唯一解！

4-4 · 演算法實作

LOG / EXP 查表法：O(1) 達成乘除法

選定生成元 α = 2 (x)，將非零元素轉為對數。
乘法轉加法，除法轉減法：

查表定理 a · b = αlogα(a) + logα(b) 
mul(a, b) {
  if (a === 0 || b === 0) return 0;
  return EXP[LOG[a] + LOG[b]];
}
div(a, b) {
  if (b === 0) throw new RangeError("Div by zero");
  if (a === 0) return 0;
  return EXP[LOG[a] - LOG[b] + 255];
}

建表初始化（一次性 255 次迴圈）

let x = 1;
for (let i = 0; i < 255; i++) {
  EXP[i] = x;
  EXP[i + 255] = x; // 雙倍防溢位
  LOG[x] = i;
  x <<= 1;          // 乘以 α (乘 2)
  if (x & 0x100) {
    x ^= 0x11d;     // 超過 8-bit 取模 P(x)
  }
}

巧妙技巧：`EXP` 設為 512 長度，指數相加無需再做 `% 255`。

4-5 · 查表核心流程與範例

查表三步驟與具體數字示範

查表三步驟視覺流程圖

a → 查 LOG 表 → log(a)
b → 查 LOG 表 → log(b)
相加 → sum → 查 EXP 表 → 乘積

乘法範例

7 × 11

  • 查 LOG 表：LOG[7] = 198、LOG[11] = 95
  • 指數相加：198 + 95 = 293
  • 查 EXP 表：EXP[293] = 49

結論：7 × 11 = 49

除法範例（驗算還原）

49 ÷ 7

  • 查 LOG 表：LOG[49] = 38、LOG[7] = 198
  • 指數相減（+255 防負數）：38 − 198 + 255 = 95
  • 查 EXP 表：EXP[95] = 11

結論：49 ÷ 7 = 11（精準整數還原）
