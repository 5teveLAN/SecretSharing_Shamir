5-1 · 還原思維

我們不需要解出完整多項式，只要 f(0)

傳統思維 · 解聯立方程

高斯消去法求所有係數

列出 k 條線性方程組解 a0, a1, ..., ak-1。
時間複雜度：O(k3)，矩陣求逆運算成本高、邏輯繁瑣。

拉格朗日插值法（推薦）

直攻截距項 f(0)

原秘密就存放在常數項 S = f(0) = a0。
時間複雜度：O(k2)，只需單純加法與連乘，套公式即得。

秘密還原等式 S = f(0) = ∑i=0k-1 yi · ℓi(0)

每個 Share 點 (xi, yi) 乘上專屬基底權重 ℓi(0) 後相加。
權重特性：ℓi(x) 在 x = xi 時為 1，在其餘給定點 xj (j ≠ i) 皆為 0。

關鍵洞察：拉格朗日基底 ℓi(0) 僅由參與還原的點座標 x 決定，與機密值 y 完全無關！

5-2 · 有限體代數適配

有限體 GF(28) 下的公式大化簡

標準實數 / 模 p 公式 ℓi(0) = ∏j ≠ i 0 − xjxi − xj

傳統算式中包含負號 −xj 與減法 xi − xj，需要處理負數取模運算。

GF(28) 特殊代數性質

  • 加法等於減法：a − b = a ⊕ b
  • 相反數等於自身：−x = x
GF(28) 專用極簡公式 ℓi(0) = ∏j ≠ i xjxi ⊕ xj

三大實作轉換：
1. 分子 0 − xj 直接簡化為 xj。
2. 分母 xi − xj 替換為 xi ⊕ xj（XOR）。
3. 分數除法與累乘呼叫 GF28.div 與 GF28.mul 查表。

零負數困擾：完全不需要像整數模運算加上質數 p 轉正，運算乾淨俐落！

5-3 · 數值計算實例

兩點還原實例：以 k = 2 為例一步步算

已知條件與 Share

設秘密 S = 123，多項式一次斜率 a1 = 45。
產生兩份 Share：
• 點 1：(x1, y1) = (1, 86)
• 點 2：(x2, y2) = (2, 33)

分母計算 x1 ⊕ x2 = 1 ⊕ 2 = 3

步驟 1：求基底係數 ℓi(0)

• ℓ1(0) = x2 / (x1 ⊕ x2) = 2 / 3 = 245
• ℓ2(0) = x1 / (x2 ⊕ x1) = 1 / 3 = 244

步驟 2：乘上 yi 並累加（XOR）

• 項 1：y1 · ℓ1(0) = 86 × 245 = 100
• 項 2：y2 · ℓ2(0) = 33 × 244 = 31
• 還原常數項：S = 100 ⊕ 31 = 123 ✓

5-4 · 程式實作

拉格朗日插值完整 JS 實作

export function lagrangeInterpolateAtZero(points, k) {
  if (!points || points.length < k) {
    throw new RangeError(`至少需要 ${k} 個點`);
  }
  const selected = points.slice(0, k);
  let secret = 0;

  for (let i = 0; i < k; i++) {
    const xi = selected[i].x;
    const yi = selected[i].y;
    let li = 1;

    for (let j = 0; j < k; j++) {
      if (i === j) continue;
      const xj = selected[j].x;
      const denom = gf.sub(xi, xj); // xi ^ xj
      if (denom === 0) throw new RangeError("重複座標");
      li = gf.mul(li, gf.div(xj, denom));
    }

    secret = gf.add(secret, gf.mul(yi, li)); // ^
  }
  return secret;
}

程式碼設計細節

  • 防呆機制
  • 零開銷乘除

1. 門檻過濾：隨意選取任意 k 個點（slice(0, k)），多給的點不影響結果。
2. 防重檢查：若 xi = xj，分母為 0 會報錯。
3. 模運算封閉：所有加、乘、除全調用 gf 庫，中間計算永不溢位。

此函式正是專案 Lagrange.js 核心，直接對接 shamir.js 的 reconstructPixel。

5-6 · 門檻還原

高斯消去法：解聯立多項式求回機密

在 (r, n) 機制中，收集任意 r 位參與者的分享值 {(x1, y1), …, (xr, yr)}。 依論文第二章，代入多項式建立 r 個聯立方程： yi = a0 + a1xi + ⋯ + ar−1xir−1

  • 1
    建立凡德蒙增廣矩陣 以點座標次方項與分享值組成 [V \mid y] 線性系統。
  • 2
    前向消去化為階梯形 在有限體以列運算（加減為 XOR、除法為乘法逆元）消為上三角矩陣。
  • 3
    反向代入求得常數項 a₀ 由下而上反向求解未知數，解得 a0 即為原影像像素通道值。

方法比較：拉格朗日插值可直算常數項 a0；高斯消去法為通用代數解法，可同時解出整條多項式所有係數。

5-7 · 數值演算（一）

先把 Share 寫成增廣矩陣，再消去一列

沿用前面的兩個 Share：(x1, y1) = (1, 86)、 (x2, y2) = (2, 33)。 一次多項式為 f(x) = a0 + a1x， 目標是由兩個已知點解出 a0 和 a1。

代入兩個點，形成增廣矩陣 [ 1　1 │ 86 ]
[ 1　2 │ 33 ]
前向消去

第一列第一欄的主元是 1。用第 1 列消去第 2 列第一欄的 1： R2 ← R2 ⊕ R1。

逐欄做 XOR（GF(28) 加法） 1 ⊕ 1 = 0
2 ⊕ 1 = 3
33 ⊕ 86 = 119
消去後的階梯形矩陣 [ 1　1 │ 86 ]
[ 0　3 │ 119 ]

在 GF(28) 中，加法就是 XOR，不是一般整數加法。 這一步把矩陣化成上三角形，接著從最後一列開始反向求解。

5-8 · 數值演算（二）

由最後一列往回解，再代回 Share 驗算

步驟 1 · 解出 a₁

最後一列代表 3a1 = 119。 在有限體中除以 3，等於乘上 3 的乘法反元素 3−1 = 244：

a1 = 119 / 3 = 119 × 244 = 45
步驟 2 · 回代求 a₀

第一列是 a0 ⊕ a1 = 86。 把剛求得的 a1 = 45 代入：

a0 = 86 ⊕ 45 = 123
代回兩個點驗算 f(1) = 123 ⊕ 45 = 86
f(2) = 123 ⊕ (45 × 2) = 123 ⊕ 90 = 33

兩個計算結果分別還原出 y1 = 86、 y2 = 33，與收到的 Share 相符； 因此秘密常數項是 123。

點數更多時，依序用每個主元消去下方欄位，得到上三角矩陣後再由下而上回代； 除法與乘法都在 GF(28) 中完成。
