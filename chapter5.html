得到 Share 後，如何還原機密

比較三種還原解密方法：拉格朗日插值法、行列式（克拉瑪公式）與高斯消去法，
在 GF(28) 有限體下精準取回常數項 f(0)。

5-1 · 還原思維

得到 Share 後，有三種方法還原機密 f(0)

方法一 · 推薦

拉格朗日插值法

不解聯立，直接構造開關基底 ℓi(0)，直攻常數項 S = f(0)。
複雜度：O(k2)

方法二 · 線性代數

行列式解密（克拉瑪公式）

將聯立方程寫成矩陣，利用克拉瑪公式直接對常數項 a0 求行列式比值 det(V0) / det(V)。
複雜度：O(k! ) 或 O(k3)

方法三 · 線性代數

高斯消去法

將 k 個點代入多項式，列成增廣矩陣消去並回代，求得所有係數 a0…ak-1。
複雜度：O(k3)

5-2 · 方法一：拉格朗日原理

核心原理：為每個點設計專屬「開關」ℓi(x)

加權合成 f(x) = ∑i=1k yi · ℓi(x)

開關性質 (Kronecker Delta)

• 在自己家：ℓi(xi) = 1
• 在別人家：ℓi(xj) = 0（j ≠ i）
代入任意 xm 時，只有 ym · 1 活著，其餘全為 0！

兩步構造：分子 ∏(x − xj) 讓別人家歸 0；分母 ∏(xi − xj) 讓自己家變 1。最後 ∑ yiℓi(0) 即得秘密！

5-2 · 方法一：拉格朗日插值法

拉格朗日插值法：GF(28) 下的公式大化簡

標準實數 / 模 p 公式 ℓi(0) = ∏j ≠ i 0 − xjxi − xj

傳統算式中包含負號 −xj 與減法 xi − xj，需要處理負數取模運算。

GF(28) 特殊代數性質

  • 加法等於減法：a − b = a ⊕ b
  • 相反數等於自身：−x = x
GF(28) 專用極簡公式 ℓi(0) = ∏j ≠ i xjxi ⊕ xj

三大實作轉換：
1. 分子 0 − xj 直接簡化為 xj。
2. 分母 xi − xj 替換為 xi ⊕ xj（XOR）。
3. 分數除法與累乘呼叫 GF28.div 與 GF28.mul 查表。

零負數困擾：完全不需要像整數模運算加上質數 p 轉正，運算乾淨俐落！

5-3 · 數值計算實例

兩點還原實例：以 k = 2 為例一步步算

已知條件與 Share

設秘密 S = 123，多項式一次斜率 a1 = 45。
產生兩份 Share：
• 點 1：(x1, y1) = (1, 86)
• 點 2：(x2, y2) = (2, 33)

分母計算 x1 ⊕ x2 = 1 ⊕ 2 = 3

步驟 1：求基底係數 ℓi(0)

• ℓ1(0) = x2 / (x1 ⊕ x2) = 2 / 3 = 245
• ℓ2(0) = x1 / (x2 ⊕ x1) = 1 / 3 = 244

步驟 2：乘上 yi 並累加（XOR）

• 項 1：y1 · ℓ1(0) = 86 × 245 = 100
• 項 2：y2 · ℓ2(0) = 33 × 244 = 31
• 還原常數項：S = 100 ⊕ 31 = 123 ✓

5-4 · 程式實作

拉格朗日插值完整 JS 實作

export function lagrangeInterpolateAtZero(points, k) {
  if (!points || points.length < k) {
    throw new RangeError(`至少需要 ${k} 個點`);
  }
  const selected = points.slice(0, k);
  let secret = 0;

  for (let i = 0; i < k; i++) {
    const xi = selected[i].x;
    const yi = selected[i].y;
    let li = 1;

    for (let j = 0; j < k; j++) {
      if (i === j) continue;
      const xj = selected[j].x;
      const denom = gf.sub(xi, xj); // xi ^ xj
      if (denom === 0) throw new RangeError("重複座標");
      li = gf.mul(li, gf.div(xj, denom));
    }

    secret = gf.add(secret, gf.mul(yi, li)); // ^
  }
  return secret;
}

程式碼設計細節

  • 防呆機制
  • 零開銷乘除

1. 門檻過濾：隨意選取任意 k 個點（slice(0, k)），多給的點不影響結果。
2. 防重檢查：若 xi = xj，分母為 0 會報錯。
3. 模運算封閉：所有加、乘、除全調用 gf 庫，中間計算永不溢位。

此函式正是專案 Lagrange.js 核心，直接對接 shamir.js 的 reconstructPixel。

5-5 · 方法二：行列式解密

行列式解密（克拉瑪公式）：直求常數項 a0

克拉瑪公式 (Cramer's Rule) S = a0 = det(V0)det(V)  (在 GF(28) 下運算)

把 k 個點寫成係數矩陣 V（第 i 列為 [1, xi, xi2, …, xik-1]）。
將 V 的第一行換成輸出向量 y 得到 V0，兩者行列式相除即為秘密 a0。

線性代數視角

為什麼不用求其他係數？

1. 目標明確：只替換對應 a0 的第一行，不必算 a1…ak-1。
2. 小門檻超好手算：當 k = 2 或 3 時，2×2 / 3×3 行列式展開非常直覺；但 k 變大時計算量會暴增。

5-6 · 方法三：高斯消去法

高斯消去法：解聯立多項式求回機密

在 (r, n) 機制中，收集任意 r 位參與者的分享值 {(x1, y1), …, (xr, yr)}。 依論文第二章，代入多項式建立 r 個聯立方程： yi = a0 + a1xi + ⋯ + ar−1xir−1

  • 1
    建立凡德蒙增廣矩陣 以點座標次方項與分享值組成 [V \mid y] 線性系統。
  • 2
    前向消去化為階梯形 在有限體以列運算（加減為 XOR、除法為乘法逆元）消為上三角矩陣。
  • 3
    反向代入求得常數項 a₀ 由下而上反向求解未知數，解得 a0 即為原影像像素通道值。

方法比較：拉格朗日插值可直算常數項 a0；高斯消去法為通用代數解法，可同時解出整條多項式所有係數。

5-7 · 數值演算（一）

先把 Share 寫成增廣矩陣，再消去一列

沿用前面的兩個 Share：(x1, y1) = (1, 86)、 (x2, y2) = (2, 33)。 一次多項式為 f(x) = a0 + a1x， 目標是由兩個已知點解出 a0 和 a1。

代入兩個點，形成增廣矩陣 [ 1　1 │ 86 ]
[ 1　2 │ 33 ]
前向消去

第一列第一欄的主元是 1。用第 1 列消去第 2 列第一欄的 1： R2 ← R2 ⊕ R1。

逐欄做 XOR（GF(28) 加法） 1 ⊕ 1 = 0
2 ⊕ 1 = 3
33 ⊕ 86 = 119
消去後的階梯形矩陣 [ 1　1 │ 86 ]
[ 0　3 │ 119 ]

在 GF(28) 中，加法就是 XOR，不是一般整數加法。 這一步把矩陣化成上三角形，接著從最後一列開始反向求解。

5-8 · 數值演算（二）

由最後一列往回解，再代回 Share 驗算

步驟 1 · 解出 a₁

最後一列代表 3a1 = 119。 在有限體中除以 3，等於乘上 3 的乘法反元素 3−1 = 244：

a1 = 119 / 3 = 119 × 244 = 45
步驟 2 · 回代求 a₀

第一列是 a0 ⊕ a1 = 86。 把剛求得的 a1 = 45 代入：

a0 = 86 ⊕ 45 = 123
代回兩個點驗算 f(1) = 123 ⊕ 45 = 86
f(2) = 123 ⊕ (45 × 2) = 123 ⊕ 90 = 33

兩個計算結果分別還原出 y1 = 86、 y2 = 33，與收到的 Share 相符； 因此秘密常數項是 123。

點數更多時，依序用每個主元消去下方欄位，得到上三角矩陣後再由下而上回代； 除法與乘法都在 GF(28) 中完成。

5-9 · 總結與比較

三種還原方法優缺點總整理

拉格朗日插值法

O(k2) · 套公式取模

優點：不解聯立、程式極簡、無須存矩陣，實務與影像還原首選。
缺點：若不預存權重，大量像素時會有重複計算 ℓi(0) 的問題。

行列式（克拉瑪公式）

O(k!) / O(k3) · 直求 a0

優點：只算第一行替換後的行列式比值，不用解出其他係數，k 很小時好手算。
缺點：k 變大時行列式展開計算量暴增，不適合大門檻程式實作。

高斯消去法

O(k3) · 解全係數

優點：線性代數標準解法，能一次求得完整多項式的所有係數 a0…ak-1。
缺點：時間複雜度高、回代步驟繁瑣，只求秘密 f(0) 時成本過高。
