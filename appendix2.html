附錄 2-3 · 介面規格 · 範例

一個介面，只回答三件事

名字叫什麼、要給它什麼、它會還你什麼 —— 用還原函式當例子。

code/shamir.js reconstructPixel(points, k) → number
  • 名稱 reconstructPixel：要還原的是「一個像素的一個通道」， 所以叫 Pixel，不叫 Image。
  • 參數 1 points: {x:number, y:number}[] —— x 是 share 編號 1…n、 y 是該張的像素值；至少 k 個。
  • 參數 2 k: number —— 門檻值（規格裡的 r）。
  • 回傳 number —— 0–255 的 secret 值， 不是陣列、不是圖片。

呼叫端（C 層）

// 每張 share 取同一個像素的 R 通道
const points = shares.map((img, i) => ({
  x: i + 1,                 // 1…n
  y: pixelAt(img, i + 1).r, // 0–255
}));

reconstructPixel(points, k);   // → 0–255

介面沒寫到的，就是還沒決定：張數不足 （points.length < k）、 x 重複、值超出 0–255， 都要先講好是 throw 還是回 NaN —— 我們選 throw。
